# BiasExploration

COMP 550 (McGill, Winter 2026) final project. We test whether **XLM-RoBERTa-Twitter** (`cardiffnlp/twitter-xlm-roberta-base-sentiment`) assigns more negative sentiment to U.S.-designated adversary countries in English than in Chinese, Russian, or Arabic, using 30 neutral templates × 30 countries balanced across adversary / ally / neutral categories (plus 5 nonsense-country baselines).

## Setup

Python 3.11+ recommended. From the repo root:

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

The notebook downloads the HuggingFace model on first run (~1.1 GB). On Apple Silicon it uses `mps`; on CUDA machines it uses `cuda`; otherwise CPU.

## Running the study

Open `main.ipynb` and run top-to-bottom. Key stages:

1. **Configuration** — country lists (30 real + 5 nonsense), template families, language set, `SEED=42`.
2. **Inference** — batches all (template × country × language) strings through the classifier, records the full softmax.
3. **Gap computation** — bipolar valence S = P(pos) − P(neg), then Gap(c) = S_EN(c) − mean(S_ZH, S_RU, S_AR).
4. **Statistics** — one-way ANOVA across categories, pre-specified directional contrast [+2, −1, −1], Kruskal–Wallis and P(neg)-only sensitivity reruns, two-way (language × category) ANOVA, Holm pairwise.
5. **Figures** — Figure 1 (heatmap), Figure 2 (interaction plot). Saved to `figures/`.

Expected runtime: ~5–10 minutes on Apple Silicon, longer on CPU.

## Key findings (see paper for full stats)

- One-way ANOVA across 30 per-country Gaps: F(2, 27) = 8.75, p = .001, η² = .39.
- Adversary-vs-rest contrast: t(27) = −4.16, one-tailed p = .0001, Cohen's d = −1.63.
- Ally vs neutral: null (Holm p = .625).
- Nonsense-country baseline (n = 5, descriptive): Gap range [−0.068, −0.015], mean −0.042 — overlaps adversary range, while ally and neutral Gaps sit above it.

## Reproducibility notes

- Seed 42 for `random`, `numpy`, `torch`.
- Model: `cardiffnlp/twitter-xlm-roberta-base-sentiment` (HF revision not pinned — whatever `main` is at download time).
- Tokenization: `max_length=128, truncation=True, padding=True, use_fast=True`.
- Inference: `batch_size=64`, fp32.
- Stats: `statsmodels.anova_lm(typ=2)`, `scipy.stats` for Shapiro–Wilk, Levene, Kruskal–Wallis, Holm via `statsmodels.stats.multitest`.
